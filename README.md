# CR Transparency Dashboard

Dashboard de transparence du Comité de Résistance

## Technologies utilisées

Ce projet est construit avec :

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Decap CMS

## Installation

Pour installer et exécuter ce projet localement :

```sh
# Clonez le dépôt
git clone https://github.com/JYLStheproducer/cr-transparency-dashboard.git

# Naviguez vers le répertoire du projet
cd cr-transparency-dashboard

# Installez les dépendances
npm install

# Démarrez le serveur de développement
npm run dev
```

## Configuration du logo

Pour utiliser votre propre logo CR :
1. Placez votre logo dans `public/images/cr-logo.png`
2. Le dashboard l'utilisera automatiquement

## Gestion du contenu

Le contenu du dashboard (membres, transactions, actualités) peut être géré via l'interface d'administration Decap CMS accessible à l'adresse `/admin` sur votre site déployé.

## Déploiement

Le projet peut être déployé sur n'importe quelle plateforme prenant en charge les applications statiques (Netlify, Vercel, GitHub Pages, etc.).
